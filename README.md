# PathWeaver

一款用于 Minecraft Forge 的路径铺设辅助 Mod。圈选一段路面截面作为「模板」，沿地形标记若干路径点，即可一键将整条道路自动铺出来。

---

## 兼容性

- **Minecraft**：1.20.1
- **Forge**：47.x（开发版本 47.4.10）
- **服务端 / 局域网联机**：完全支持，数据按玩家独立存储

---

## 获取物品

使用 7 根**木棍**按如下图案合成「路径编织器」：


## 使用流程

### 第一步：选取模板截面

模板是路面的「横截面」，工具会沿路径方向重复复制并铺出这个截面。

1. **右键单击**截面的一个角落方块 → 标记**角点1**
2. **右键单击**截面对角的方块 → 标记**角点2**
3. **面朝路径的走向**（即你希望路延伸出去的方向），**Shift+右键单击**截面内任意方块 → 确认模板

> **注意：** 只要触发角点标记（无论是角点1还是角点2），当前所有路径点都会被立即清除。  
> 模板确认后，角点选区自动清除；模板本身持续保留，直到重新 Shift+右键确认一次新模板为止。

---

### 第二步：标记路径点

**左键单击**地面方块，沿你想要的路线依次标记路径点，最多 **256** 个。

持握工具时会实时显示预览：

| 颜色 | 含义 |
|------|------|
| 橙色线框 | 角点1 / 角点2 位置 |
| 黄色连线 | 相邻路径点之间的连线 |
| 青色小方框 | 已标记的路径点 |
| 绿色线框 | 模板将被铺设的位置预览（需已有模板且有路径点） |

---

### 第三步：生成路径

**Shift+左键单击**任意方块 → 开始生成。

- **生存模式**：自动检查背包材料，不足时提示缺少的物品名和数量，不消耗任何材料；足够时扣除并生成。
- **创造模式**：不消耗材料，直接生成。

---

## 铺设模式

按 **Shift+滚轮** 切换模式，切换时路径点会被清除。

### LINEAR · 直线模式（默认）

- 至少需要 **2 个**路径点
- 相邻路径点之间按直线等距铺设，Y 坐标在两点之间线性插值
- 每隔「模板长度」放置一次截面
- 切换提示：`路径模式切换为: 直线 (LINEAR)`

### BEZIER · 贝塞尔曲线模式

- 至少需要 **3 个**路径点
- 每 **3 个点**构成一段二阶贝塞尔曲线，相邻段共用端点
  - **奇数序号点**（第1、3、5…个）：曲线端点（也是相邻两段的连接点）
  - **偶数序号点**（第2、4、6…个）：控制点，决定弯曲方向，本身不一定在曲线上
- 点数建议为 **2n+1**（3、5、7…），多余的最后一个点会被忽略
- 转弯处自动插入补丁砖，避免内侧出现空洞
- 切换提示：`路径模式切换为: 贝塞尔曲线 (BEZIER)`

## 撤销操作

所有撤销通过 **Shift+右键** 触发，每次只退一步，工具自动根据当前状态决定执行哪步。

### Shift+右键空气（逐步退回，推荐）

| 当前状态 | 执行效果 |
|---------|---------|
| 有角点2 | 清除角点2 |
| 有角点1（无角点2） | 清除角点1 |
| 有路径点 | 移除最后一个路径点 |
| 以上均无 | 撤销最近一次生成（最多可连续撤销 **10** 次） |

### Shift+右键方块（上下文操作）

| 当前状态 | 执行效果 |
|---------|---------|
| 已选好角点1和角点2 | 确认模板（不是撤销，而是正常确认流程） |
| 有路径点（角点未选完） | 移除最后一个路径点 |
| 以上均无 | 撤销最近一次生成 |

---

## 注意事项

- 撤销会跨维度正确还原方块（放置时记录了所在维度），无需在同一维度触发
- 材料检查按**物品类型**汇总，同一物品不同朝向的方块状态（如不同朝向的楼梯）视为同一种材料
- 路径点的 Y 坐标由你点击方块时的位置决定，模板的高度层会在该 Y 坐标基础上叠加
- 贝塞尔控制点的 Y 坐标同样参与曲线计算，会影响路径在垂直方向上的弯曲
